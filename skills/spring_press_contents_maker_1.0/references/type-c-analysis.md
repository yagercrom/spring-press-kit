# C형 — 이슈 심층 분석형

외부 사건·현상(기업 채용 변화, 정부 정책 발표 등)을 교육의봄 관점에서 분석·해석하는 유형. A형과의 결정적 차이는 **수치가 우리 것이 아니라는 점**이다. 자체 조사가 아니라 남의 발표·기사·통계를 재료로 쓰므로, 신뢰도는 조사 개요가 아니라 **출처 목록**에서 나온다.

★태그: `[★심층보도]`

## 메일 제목

```
[★심층보도] '[수식어]' [주체], [핵심 변화]… [파급 결과](+상세 분석)
```

예: `[★심층보도] '취업선호 1위' SK하이닉스, 채용에서 학력 제한 전면 폐지… 직업계고·마이스터고 지원률 상승 등 교육 현장까지 바뀐다(+상세 분석)`

앞의 수식어(`'취업선호 1위'`)가 왜 이 사건이 중요한지를 한 마디로 압축한다. 그냥 기업명만 쓰면 기사 가치가 전달되지 않는다.

## 헤드라인은 변화와 파급으로 쓴다

```
학력 제한 폐지, 교육 현장까지 바꾼다 — 직업계고·마이스터고 지원률 상승
```

`[변화] → [파급]` 구조. 교육의봄이 이 사건을 다루는 이유가 헤드라인에 이미 들어 있어야 한다. 채용 변화가 **교육에 미치는 영향**이 그 이유다.

## 본문 구조

```
❏ 핵심 내용 요약 (명사형) — 5개 내외 bullet
   발표 사실 / 시점 / 의미 / 평가
─────────────────────────
1. [발표 상세]
2. [산업·사회 파급]
3. [교육 현장 변화]        ← 이 블록이 C형의 존재 이유
4. [정부 정책 방향]
─────────────────────────
■ 실현 과제 및 제언 (명사형)
   1. [과제] → 문제점 → 개선안:
   2. [과제] → 우려 → 필요 조치:
■ 클로징 (존댓말)
참고자료 출처 목록          ← C형 전용, 생략 불가
발행정보 / 문의
```

A형의 세 박스 대신 `❏ 핵심 내용 요약` 하나만 쓴다. plan에서는 `overview_box` 에 요약 5줄을 넣고 `summary_box` · `implication_box` 는 비운다.

## 본문은 번호 소제목으로

`■ 결과N` 이 아니라 `1.` `2.` `3.` 번호 소제목을 쓴다. plan의 `blocks[].title` 을 `1. 발표 상세` 형태로 쓴다.

권장 순서는 **사실 → 산업 파급 → 교육 파급 → 정책 방향**이다. 이 순서를 지키는 이유는 3번(교육 현장 변화)이 교육의봄이 이 사건을 다루는 명분이고, 1·2번이 그 명분의 근거이기 때문이다. 교육 파급을 앞에 두면 근거 없는 주장처럼 읽히고, 빼면 이 자료를 왜 교육 단체가 내는지 설명되지 않는다.

## 표는 외부 지표 비교로

A형의 집단 비교와 달리 **이전/현재 2열 비교**가 기본형이다.

```
학교명          | 이전 경쟁률 | 현재 경쟁률
○○마이스터고    | 1.2 : 1     | 2.8 : 1
```

```
연도  | 인력 수요
2026  | 12,000명
2030  | 31,000명
```

변화를 보여주는 것이 목적이므로 단일 시점 표는 피한다. 수치 옆에 출처를 `※` 로 붙인다.

## 언론 평가를 인용한다

C형에만 있는 요소다. 우리 평가만 적으면 단체 의견에 그치지만, 언론 평가를 인용하면 사회적 반응이 된다.

```
주요 언론들은 이를 "교육의 작은 혁명"으로 평가
```

인용은 반드시 원문 그대로, 큰따옴표로, 출처를 밝힌다. 요약해서 인용부호를 붙이면 안 된다.

## 제언은 '실현 과제' 형태

A/B형의 '기관 입장 및 향후 계획'과 명칭·구조가 다르다. C형은 **'실현 과제 및 제언'** 이고, 각 과제를 문제점→개선안 쌍으로 제시한다.

```
1. 지원서 서식 개편 필요
   [문제점 서술]
   개선안: [구체적 조치]

2. 전형 절차의 공정성·접근성 강화
   [우려 서술]
   필요 조치: [구체적 조치]
```

변화를 만든 주체(기업·정부)를 비판하는 자리가 아니다. 이미 일어난 변화가 실제로 작동하려면 무엇이 더 필요한지를 적는다.

## 참고자료 출처 목록 — 생략하면 자료가 무너진다

C형 본문 말미에 인용한 자료의 출처를 모두 나열한다. plan에서는 마지막 `blocks` 항목이나 `position` 에 넣는다.

```
[참고자료]
- 경향신문, 「…」, 2026. 7. 15.
- 연합뉴스, 「…」, 2026. 7. 16.
- 교육부 보도자료, 「…」, 2026. 6. 30.
- 대한민국정책브리핑, 「…」
```

A형은 우리가 데이터를 만들었으므로 조사 개요가 신뢰도를 담보하지만, C형은 남의 자료를 해석한 것이다. 출처가 없으면 어디까지가 사실이고 어디부터가 교육의봄 해석인지 독자가 구분할 수 없다. **출처를 확인할 수 없는 내용은 아예 쓰지 말 것** — 기억이나 추정으로 기사·통계를 인용하면 안 된다.
