# B형 — 회견·성명 보도형

기자회견·공동성명 등 행사와 입장 발표를 알리는 유형. A형과 결정적으로 다른 점은 **독자가 알아야 할 첫 정보가 수치가 아니라 "언제 어디서 누가"** 라는 것이다. 기자는 이 자료를 보고 취재를 갈지 결정한다.

★태그: `[★회견보도]`

## 메일 제목에 날짜와 요일을 넣는다

A/C형과 다른 유일한 제목 규칙이다.

```
[★회견보도] M/D(요일) : [주최 집단], [주제] 기자회견
```

예: `[★회견보도] 8/18(화) : 교육 3단체, 수능·내신 논·서술형 절대평가 전환 촉구 기자회견`

날짜·요일이 없으면 기자가 일정을 잡을 수 없다. 이미 끝난 회견의 결과 보도라면 과거 날짜를 그대로 쓰고 본문에서 개최 사실을 밝힌다.

## 헤드라인은 슬로건을 써도 된다

A형(수치 중심)·C형(변화 서술)과 달리 B형 헤드라인은 **요구·촉구 메시지**가 중심이고 슬로건성 문구가 허용된다.

```
해방 81년, 이제 생각의 해방으로 — 수능·내신 논·서술형 절대평가로 전환 촉구
```

다만 슬로건만 두지 말고 대시(`—`) 뒤에 무엇을 촉구하는지 구체적으로 붙인다.

## 본문 구조

```
❏ 기본 정보 (명사형)
   - 행사일 / 시간 / 장소
   - 주최 단체 — 공동이면 전 단체 명기
   - 주제
❏ 핵심 주장 (명사형)
   - bullet로 회견의 핵심 논리
─────────────────────────
첫째 - [요구사항]
   [근거·설명]
둘째 - [요구사항]
   …
─────────────────────────
■ 기관 입장 및 향후 계획 (명사형)
■ 클로징 (존댓말)
발행정보 / 문의 — 참여 기관 전부
```

A형의 세 박스(개요·결과요약·시사점) 대신 `❏ 기본 정보` + `❏ 핵심 주장` 두 블록을 쓴다. plan에서는 `overview_box` 에 기본 정보를, `summary_box` 에 핵심 주장을 넣고 `implication_box` 는 비운다.

## 요구사항은 `첫째~` 로 나열한다

A형의 `■ 결과N` 자리에 요구사항이 온다. plan의 `blocks[].title` 을 `첫째 - …` 형태로 쓴다.

```
첫째 - 국가교육발전계획에 논·서술형 평가로의 단계적 전환을 명시적으로 담을 것
둘째 - …
다섯째 - 충분한 예고 기간과 현장 준비 지원 보장
```

각 항목에 근거·설명 문단을 붙인다. 요구사항 제목은 `~할 것`, `~보장` 처럼 **명사형·요구형**으로 끝낸다. 설명 문단은 존댓말.

3~5개가 적당하다. 그 이상이면 기자가 무엇이 핵심 요구인지 판단하지 못한다.

## 반박 논리를 명시한다

B형에만 있는 요소다. 예상되는 반론을 먼저 꺼내 되받는다.

```
'채점 공정성을 담보할 수 없다'는 우려에 대해 "이미 여러 국가가 …로 해결하고 있다"라고 반박
```

이걸 넣는 이유는 기자가 반대 측 코멘트를 받으러 갔을 때 우리 논리가 이미 자료에 들어 있어야 균형 보도에서 밀리지 않기 때문이다.

## 어조

`~ 촉구`, `~ 요구` 같은 강한 어조가 허용되는 유일한 유형이다. 다만 A형과 공통되는 원칙은 그대로다 — 사실 진술과 기관 주장을 섞지 않는다. 행사 정보·발언 인용은 사실로, 요구·평가는 기관 입장으로 층을 나눈다.

## 공동 발행 처리

B형은 공동 주최가 많다. 이때 두 곳을 반드시 손본다.

1. **발행정보** — 참여 기관을 모두 병기
2. **문의처** — 기관별 담당자·직책·전화번호를 나란히

```
문의: 교육의봄 부대표 안상진(02-6338-0660) / 사교육걱정없는세상 공동대표 신소영(02-797-4044) /
      좋은교사운동 정책위원장 장승진(02-876-4078)
```

담당자나 연락처가 확실하지 않으면 **추측하지 말고 물어볼 것.** 잘못된 연락처는 공동 주최 기관에 직접 피해가 간다.

기관 입장 블록의 주어도 공동 주체로 바꾼다 — 교육의봄 단독 명의로 쓰면 공동성명의 성격이 흐려진다.
